# AI Business Assessment

Automated AI audit for SMBs. Voice intake → Claude analysis → PDF report → $1,000/assessment + $3–5K upsell. Live at **[snapaireport.com](https://snapaireport.com)**.

## Stack

- **Next.js 15** with TypeScript and Tailwind CSS
- **Retell AI** for voice intake
- **Claude API** for report generation
- **@react-pdf/renderer** for PDF reports
- **Resend** for email delivery
- **Cal.com** for booking
